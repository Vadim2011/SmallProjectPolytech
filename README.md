* Генерация паролей 
* Проверка СНИЛС, ИНН

Использую в работе генерацию паролей для пользователей внутреннего контура.
Необходимо создавать пароли от 6 до 8 символов, верхний и нижний регист, цифры, спец. символы. 
Жалааатеельно использовать пароли которые легко набирать 1н спец. символ, 
по 1му символу верх. и ниж. регистра.

Дополнительно в работе использую валидацию СНИЛЫ, ИНН.
