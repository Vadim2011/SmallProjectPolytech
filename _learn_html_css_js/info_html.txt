========= BEM
Блок / Элемент / Модификатор
!!! КЛФЫЫ - К какой БЭМ сущности он относится

Бдок - компонент множественное использование
*Повторное использование
- Что это .about .menu
- нет внешней геометрии marg posit rel + top .. not
(нет стилей влияющих на внешнее окружение)
- блок можно вкладывать в блок
  <div class="about">
    <h2 class="title">item 2</h2>
  </div>
# .header / product-card / about-product / footer


Элемент - состовная часть блока не может использоваться без него
- Что это  .menu > .menu_link
- часть блока, НЕ часть элемента
.menu 
  .menu__link
  .menu__link
    .menu__item

Модификатор - дополняет уточняет стиль блока либо элемента
- какой как выглядит, состояние
.menu 
  .menu__link
  .menu__link .menu__link--active

.button .botton--big .button--bordered
.products
  .products__item
  .products__item .products__item--wide

Микс
.about
  .about__title title
  .about__subtitle subtitle
